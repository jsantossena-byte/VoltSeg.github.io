VOLTSEG — SITE DEMONSTRATIVO
============================

Como abrir: extraia o ZIP e abra voltseg_site/index.html em um navegador.

Recursos: catálogo, busca, filtros, carrinho, seleção de Pix/boleto/cartão de débito/crédito, registro demonstrativo de pedidos, área do funcionário para adicionar/editar/excluir produtos e upload de imagens.

Acesso de demonstração: usuário funcionario | senha voltseg123

IMPORTANTE SOBRE PAGAMENTOS: as formas de pagamento são opções demonstrativas. O site registra o método escolhido e o pedido como Aguardando pagamento, mas NÃO gera QR Code/copia e cola Pix, boleto bancário nem processa cartões. Para receber pagamentos reais, é necessário integrar um provedor de pagamento no servidor. Nunca armazene dados completos de cartão no navegador.

IMPORTANTE SOBRE SEGURANÇA: login e dados ficam no navegador e não são adequados para produção. Para uso real, são necessários backend, banco de dados, autenticação segura e HTTPS. As câmeras são imagens estáticas ilustrativas.
